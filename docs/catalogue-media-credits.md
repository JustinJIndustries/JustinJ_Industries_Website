# Catalogue preview source and media credits

The catalogue contains public-facing fictional demonstrations. All concept businesses are fictional;
no real commission, client result, or trademark clearance is claimed. Only the
files listed below were extracted from owner-supplied Library source archives.
Source ZIPs, WordPress runtimes, database files, admin scripts, and credentials
are not in the public build allowlist. The static WordPress studies below are
reconstructions from public-facing theme templates, demo page bodies, seed copy,
theme CSS, and approved media. They do not execute WordPress or reproduce the
private admin environment. Demo forms are visibly inactive.

## Multi-page static studies

- `previews/harbor-ledger/` contains Home, Services, About, FAQ, and Contact.
  The page bodies came from `wordpress-five-page-starter.zip` at
  `redesign/pages/*.html`; `source.css` is `redesign/harbor.css`. The two
  workspace photos came from `assets/harbor-ledger/` in that archive and were
  generated for the fictional demo. The public Contact study replaces the
  local WPForms shortcode with disabled illustrative fields.
- `previews/still-form/` contains Home, Work, Services, About, and Contact.
  Layout classes and styling come from `still-form-theme/` in
  `still-form-source.zip`; copy, service cards, project names, and categories
  follow the companion's demo seed. Six photos came from
  `still-form-companion/assets/photos/`. The archive's `PHOTO-CREDITS.md`
  records each source and license. Credits appear beside the relevant project
  cards in the public study: Luke Thornton, Missy Meyer, Giorgio Trovato,
  Hannah Busing, Florencia Simonini, and Scott Taylor, each via Unsplash.
- `previews/aer-field/` contains Home, Film, Services, About, Contact, and
  three fictional film detail pages.
  Layout classes, styling, and the mobile menu script come from
  `aer-field-theme/` in `aer-field-source.zip`; copy and film/service names
  follow the source defaults and demo seed. The five poster frames, five web-size MP4 files, and six gallery frames
  came from `aer-field-companion/assets/media/web/`. Source credits recorded
  in `MEDIA-SOURCES.md` are Honye Sanges (desktop Home), Petkevich Evgeniy
  (mobile Home), Curtis Adams (Golf), just a hobby (Real Estate), and TR Studio
  (Business), via Pexels. Footage credits appear beside the media and on each detail page. The public
  study contains working video playback and still omits admin code.

The static studies preserve the page hierarchy, text, image choices, and CSS
from their source demos while omitting WordPress-only editing, live filters,
and form submission. AER/FIELD includes fictional film detail routes and
playable footage; those advanced media features are scoped separately from the website setup starting price.
